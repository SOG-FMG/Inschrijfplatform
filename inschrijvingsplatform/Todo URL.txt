3. Wrangler config aanpassen

  "name": "event",
  "main": "./worker/index.ts",
  "compatibility_date": "2026-09-30",
  "workers_dev": true,
  "services": [
    { "binding": "API", "service": "event-api" }
  ]
}

4. Deployen (VS Code terminal — Ctrl+`)
# Stap 1: API Workers eerst (zodat service bindings bestaan)
npx wrangler deploy --config wrangler.event-api.jsonc
npx wrangler deploy --config wrangler.event-api-test.jsonc

# Stap 2: Secrets overzetten naar nieuwe API Workers
npx wrangler secret put TURNSTILE_SECRET --config wrangler.event-api.jsonc
npx wrangler secret put ENCRYPTION_KEY --config wrangler.event-api.jsonc
npx wrangler secret put HOOFDADMIN_SETUP_CODE --config wrangler.event-api.jsonc
npx wrangler secret put MAIL_WEBHOOK_SLEUTEL --config wrangler.event-api.jsonc
npx wrangler secret put MAIL_WEBHOOK_URL --config wrangler.event-api.jsonc

npx wrangler secret put ENCRYPTION_KEY --config wrangler.event-api-test.jsonc
npx wrangler secret put HOOFDADMIN_SETUP_CODE --config wrangler.event-api-test.jsonc

# Stap 3: Frontend Workers deployen
npx wrangler deploy --config wrangler.event.jsonc
npx wrangler deploy --config wrangler.event-test.jsonc
5. Passkeys — code controle
In je API code, zoek waar de rpId voor passkeys bepaald wordt. Als het hardcoded staat:

rpID: "fmg-inschrijfplatform.freinetmiddenschool-automatisatie.workers.dev"
verander dit naar:

rpID: "event.middenschool.workers.dev"
Als het dynamisch is (bijv. new URL(env.PUBLIC_APP_URL).hostname), dan gebeurt dit automatisch mee met de PUBLIC_APP_URL wijziging`

⚠️ Bestaande passkeys werken niet meer op het nieuwe domein. Gebruikers moeten opnieuw registreren.

6. Oude Workers verwijderen (na controle!)
npx wrangler delete --name fmg-inschrijfplatform
npx wrangler delete --name fmg-inschrijfplatform-test
npx wrangler delete --name inschrijvingsplatform-api
npx wrangler delete --name inschrijvingsplatform-api-test
